# AgiCrypto

Projeto de plataforma **web responsiva de carteira de criptomoedas**, desenvolvido como exemplo para estudo e apresentação de arquitetura monorepo.

---

## 💻 Tecnologias Utilizadas

### Backend (Java / Spring Boot)
- **Spring Web**: API REST para comunicação com o frontend
- **Spring Data JPA**: Mapeamento ORM para PostgreSQL
- **PostgreSQL Driver**: Conexão com banco de dados Aiven
- **Validation**: Validação de campos (email, senha, obrigatório)
- **DevTools**: Hot reload durante desenvolvimento
- **Lombok**: Reduz código repetitivo com getters, setters e construtores

### Frontend (React / Vite)
- **React**: Biblioteca para criar interface dinâmica
- **Vite**: Ferramenta de build rápida para React

- **Axios / Fetch**: Chamadas para o backend

### Banco de Dados
- **Aiven PostgreSQL**: Banco de dados na nuvem
- **DBeaver**: Cliente desktop para visualização e administração das tabelas
